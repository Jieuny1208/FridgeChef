---
name: 한국어 UI 카피 톤
description: FridgeChef에서 사용자 노출 카피의 톤·문법·동사형 규칙
type: feedback
---

**규칙:**
- "~하세요"와 "~해 주세요"를 일관되게. 짧고 단정한 안내는 "~하세요", 사용자에게 무언가 부탁할 때는 "~해 주세요".
- 버튼·링크 라벨은 동사형으로 행동을 명확히: "레시피 추천받기", "재료 확인하기", "다시 시도하기". (단순 "확인"보다 의도가 분명한 표현 선호)
- 에러는 비난하지 않는 톤: "이미지를 인식하지 못했어요. 조금 더 밝은 사진으로 다시 시도해 보시겠어요?" 식. 사용자 잘못이라는 인상 금지.
- 기술 용어 노출 금지: HTTP 상태코드, traceback, "JSON 스키마 검증 실패" 등은 사용자 카피로 그대로 노출하지 말 것. 내부 로그/expander에는 OK.

**Why:** 사용자는 한국어 화자이고, 학습 프로젝트지만 카피의 정중함과 행동 지향성이 사용성에 큰 영향을 미친다. "에러"보다 "다음에 무엇을 할지"가 중요.

**How to apply:** 새 카피 작성/수정 시 (1) 동사형 (2) 친근/정중 (3) 다음 액션 지시 — 이 세 가지 중 적어도 두 개를 만족시키도록.
